# nutriScan (minimal Expo template)

This repository contains a minimal Expo-managed React Native app (TypeScript) with a single `index.tsx` entry and CI for linting, formatting, typechecking, and tests.

Local checks

```bash
# install deps
npm ci

# run dev server
npm start

# run linters + checks
npm run lint
npm run format:check
npm run typecheck
npm test
```
